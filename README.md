# Agent01: Autonomous Local AI Task-Automation Agent

Agent01 is a local, lightweight task-automation agent built in pure Python. It uses a local Ollama instance running `llama3.1:latest` to reason, choose tools, evaluate business thresholds, verify file artifacts, and trigger external automation services (n8n).

---

## 1. Architecture & Design Principles

```
                  +----------------------------------+
                  |         Goal / Directive         |
                  +----------------------------------+
                                   |
                                   v
                  +----------------------------------+
                  |    Agent Orchestrator (ReAct)    |
                  +----------------------------------+
                                   |
           +-----------------------+-----------------------+
           |                                               |
           v                                               v
+---------------------+                         +---------------------+
|   Local LLM (Ollama)|                         |    Tool Registry    |
|   llama3.1:latest   |                         +---------------------+
+---------------------+                                    |
           |                                               |
           v                                               v
   [Structured JSON]                             [Local Python Tools]
   • thought                                     ├── dataset_tool.py
   • action                                      ├── excel_tool.py
   • action_input                                ├── file_tool.py
                                                 └── n8n_tool.py
                                                           |
                                                           v
                                                 [External n8n Webhook]
```

### Responsibility Separation
* **Agent01 (The Brain & Evaluator)**:
  * Understands high-level goals.
  * Inspects data and counts records.
  * Evaluates conditions/thresholds autonomously without hardcoded `if/else` wrappers.
  * Selects tools and inspects execution observations.
  * Verifies generated files on disk.
* **n8n (The Workflow Executor)**:
  * Runs predefined workflow chains (sending emails, Slack alerts, updating CRMs).
  * Does not contain agent logic; it acts only when Agent01 decides to trigger its webhook.

## 3. How to Run Agent01

### Prerequisites
1. **Ollama**: Ensure Ollama is running with `llama3.1:latest`:
   ```powershell
   ollama serve
   ollama pull llama3.1:latest
   ```

2. **Python Environment**: Use the provided virtual environment `.venv`:
   ```powershell
   # If installing packages:
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   ```

---

### Execution Commands

#### 1. Run the Full Agent Automation (Threshold = 30 $\rightarrow$ Condition Met)
The dataset contains 32 employees. With threshold 30, the agent:
1. Counts records (32).
2. Determines $32 \ge 30$.
3. Generates the Excel report (`output/employee_report.xlsx`).
4. Verifies the file on disk.
5. Triggers the n8n webhook.
6. Reports the final summary.

```powershell
.\.venv\Scripts\python.exe agent.py 30
```

#### 2. Run with Unmet Threshold (Threshold = 50 $\rightarrow$ Condition NOT Met)
With threshold 50, the agent:
1. Counts records (32).
2. Determines $32 < 50$.
3. **Refuses** to generate the Excel report or trigger n8n.
4. Concludes that the threshold was not reached.

```powershell
.\.venv\Scripts\python.exe agent.py 50
```

#### 3. Run the Unit Test Suite
To verify all tools, file checks, Excel generation, and error handling independently:

```powershell
.\.venv\Scripts\python.exe -m unittest tests/test_tools.py
```

## 4. Testing the n8n Webhook Integration

You can test the n8n integration in two ways:

### Option A: Using the Included n8n Mock Server (Instant, Zero Setup)
We included a lightweight simulator `mock_n8n.py` that listens on port 5678:
1. In a separate terminal, start the mock n8n server:
   ```powershell
   .\.venv\Scripts\python.exe mock_n8n.py
   ```
2. In your main terminal, run Agent01:
   ```powershell
   .\.venv\Scripts\python.exe agent.py 30
   ```
   You will see:
   * **Step 4**: `trigger_n8n_webhook` returns `HTTP 200: Successfully triggered n8n webhook`.
   * **mock_n8n terminal**: Prints the incoming payload and logs the downstream action!

---

### Option B: Using Real n8n
1. Start your local n8n instance:
   ```bash
   npx n8n
   ```
2. Create a workflow in n8n:
   * Add a **Webhook** node.
   * Method: **POST**
   * Path: `webhook/employee-threshold-reached`
3. Run `.\.venv\Scripts\python.exe agent.py 30`. Agent01 will post directly to your real n8n workflow.
